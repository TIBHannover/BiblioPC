Jinja2- und HTML5 Frontend-Templates für das Verwaltungssystem **BiblioPC**.

| Datei | Beschreibung / Verwendungszweck |
| :--- | :--- |
| **`base.html`** | Main-Layout und Master-Template. Stellt die HTML5-Grundstruktur, den Head-Bereich sowie die Hauptnavigation bereit. |
| **`login.html`** | Eigenständige Anmeldeseite für das Bibliothekspersonal (Bearbeiter) zum Einloggen in die Verwaltungsoberfläche. |
| **`uebersicht.html`** | Übersicht der aktuell an den PC-Terminals angemeldeten Benutzer inklusive Option zur Freigabe/Abmeldung hängender Sitzungen. |
| **`benutzerverwaltung.html`** | Formular und Tabelle zur Anlegung und Verwaltung lokaler Gast- oder Sonderbenutzerkonten. |
| **`benutzersperren.html`** | Verwaltung von zeitlich befristeten oder dauerhaften Benutzersperren. |
| **`benutzerzeitkontingent.html`** | Anpassung und Erhöhung individueller Wochen-Zeitlimits (Zeitkontingente) für bestimmte Benutzernummern. |
| **`benutzerstatistik.html`** | Abruf von verbrauchter Online-Zeit, Restguthaben sowie einer detaillierten Aktivitäts-Historie für einen spezifischen Benutzer. |
| **`tagesprotokoll.html`** | Protokollanzeige aller Systemereignisse und Anmeldungen aufgeschlüsselt nach Terminal-PC (Host) und Datum. |
| **`bearbeiterverwaltung.html`** | Anlegen und Löschen von Administratoren- und Bearbeiter-Zugängen für die Verwaltungssoftware. |
| **`passwort-aendern.html`** | Formular zum Ändern des eigenen Bearbeiter-Passworts. |
