# Installationsskripte

Die Skripte stammen aus OPSI und können als Vorlagen für eigene Installationsskripte genutzt werden. Variablen, die mit zwei $-Zeichen umschlossen sind, dienen nur als Platzhalter, da sie in der Bash so nicht funktionieren.

**una-pam-login** - Installiert das PAM-Modul auf dem Ubuntu-Client
